Turns a passage into `n` search-style questions that it answers: the queries a user would type to find it. Built for **training and testing search and RAG systems in bulk**: run your corpus through it to get `(query, passage)` pairs for fine-tuning retrievers and rerankers, or a test set that checks your search finds the right passage. It also works for FAQs and study cards. Powered by [mist-qg-1.5b](https://huggingface.co/olaverse/mist-qg-1.5b).

The questions are always in the **passage's own language**: a Yorùbá passage gives Yorùbá questions. The language is detected for you; the model does not translate.

```python
r = call("/v1/questions/generate", {
    "passage": "Ocean tides are caused mainly by the gravitational pull of the Moon on the Earth...",
    "n": 3})
print(r["questions"])
```

## Request

| Field | Default | Notes |
| --- | --- | --- |
| `passage` | required | 1 to 8,000 characters. Works best at paragraph length. |
| `n` | `3` | 1 to 10 questions. |
| `language` | detected | Optional. The passage's language, as a name or code: `yor`, `yo` or `Yoruba`. One of the [25 supported languages](#supported-languages). If the passage is clearly in a different supported language, that one is used and `warnings` says so. |

## Response

```json
{"questions": ["What causes ocean tides?", "...", "..."], "language": "eng",
 "model": "olaverse/mist-qg-1.5b", "warnings": [],
 "usage": {"input_tokens": 96, "output_tokens": 27, "generations": 1}}
```

`language` is the language the questions are in. `warnings` flags a very short passage, a language the model is less confident in, a passage whose language couldn't be told (the questions are then in English), or a `language` that didn't match the passage.


## Supported languages

**Ready (16 languages):** Afrikaans, Dutch, English, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Polish, Portuguese, Russian, Spanish, Turkish, Vietnamese and Xhosa.

**Beta, free (7 languages):** Amharic, Hausa, Igbo, Shona, Somali, Swahili, Yorùbá and Zulu. In these languages the model often restates a sentence of the passage instead of asking about it, so for now they're free, with safeguards:

- Restated sentences are dropped before you get the response, so you may get fewer than `n` questions; `warnings` says how many were dropped.
- At most **3 questions** per passage.
- Every response carries a `warnings` entry saying the language is in beta.

We're retraining the model for these languages and will take them out of beta when the questions are good enough to charge for.

## Batch

`POST /v1/questions/generate/batch` with `"passages": [...]` (up to **64**, in any mix of supported languages) returns `{"results": [[...], [...]], "languages": [...]}`, with each passage's language in `languages`.
