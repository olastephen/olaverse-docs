Turns a passage into the questions it answers, in your own words rather than copied from the text. Built for **training and testing search and RAG systems in bulk**: run your corpus through it to get `(question, passage)` pairs for fine-tuning embedders and rerankers, or a test set that checks your search finds the right passage. It also works for FAQs and study cards. Powered by [MIST-QG-1.1](https://huggingface.co/olaverse/MIST-QG-1.1), trained on passages in 324 languages.

```python
r = call("/v1/questions/generate", {
    "passage": "Ocean tides are caused mainly by the gravitational pull of the Moon on the Earth...",
    "n": 3})
print(r["questions"])
```

## Request

| Field | Default | Notes |
| --- | --- | --- |
| `passage` | required | 1 to 8,000 characters. Works best at paragraph length, up to about 2,000 characters; split longer documents into passages. |
| `n` | `3` | How many questions: 1 to 5, or `"auto"` to let the model write as many as the passage supports (usually about two). Values up to 10 are accepted and capped at 5. |
| `language` | detected | Optional. The passage's language, as a name or code: `yor`, `yo` or `Yoruba`. Detected for you when left out. |
| `question_language` | the passage's | Optional. Write the questions in another language: see [Cross-lingual questions](#cross-lingual-questions). |

## Response

```json
{"questions": ["What causes ocean tides?", "...", "..."], "language": "eng", "question_language": "eng",
 "model": "mist-qg-1.1", "warnings": [],
 "usage": {"input_tokens": 96, "output_tokens": 27, "generations": 1}}
```

`language` is the passage's language and `question_language` the questions'. `warnings` flags a very short or very long passage, a passage whose language couldn't be told, a count above 5, or a passage that supports fewer distinct questions than you asked for.

## How many questions

- **A number, across languages:** you get exactly that many, from 1 to 5.
- **A number, in the passage's own language:** it's a maximum. A short passage that only supports two good questions gives two, not five padded ones, and `warnings` says so.
- **`"auto"`:** the model decides from the passage. Use it when every question must be one the text really answers, such as training pairs.
- **Repeats are removed.** If the model writes the same question twice, or two near-identical versions of it, you get it once, `warnings` says so, and you aren't charged for the removed ones.

## Cross-lingual questions

Set `question_language` to get questions in a different language from the passage:

- **Any passage → English or French.** A Yorùbá, Quechua or Hausa passage can give English or French questions.
- **English or French passage → 30 widely spoken languages:** Afrikaans, Amharic, Arabic, Bengali, Chinese, Dutch, German, Hausa, Hindi, Igbo, Indonesian, Italian, Japanese, Korean, Persian, Polish, Portuguese, Russian, Somali, Spanish, Swahili, Tamil, Telugu, Thai, Turkish, Ukrainian, Urdu, Vietnamese, Yoruba and Zulu.
- **Between any two of those 30**, such as Swahili → Hindi.

Other directions return `400` with the reason.

```python
r = call("/v1/questions/generate", {
    "passage": "Ọjà Ọ̀jọ̀ jẹ́ ọjà ìbílẹ̀ tó gbajúmọ̀ ní ìlú Ìbàdàn...",
    "question_language": "English", "n": 2})
```

## Batch

`POST /v1/questions/generate/batch` with `"passages": [...]` (up to **64**, in any mix of languages, with the same `n`, `language` and `question_language` fields) returns `{"results": [[...], [...]], "languages": [...], "question_languages": [...]}`.

<Aside type="note">
`mist-qg-1.5b` was the previous model on this endpoint. Requests that name it are answered by MIST-QG-1.1.
</Aside>
