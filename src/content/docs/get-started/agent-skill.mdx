The Olaverse skill teaches coding agents the API: endpoints, request and response shapes, question and template types, batch limits, rate limits and how to retry. With it installed, you can ask your agent to "triage these support tickets with Olaverse" or "pull the amount and date out of these MoMo messages" and get working code.

## Install

From your project's root:

```bash
npx skills add https://docs.olaverselab.com --skill olaverse-api
```

The installer asks which agents should get the skill. Then give your code a key from the [developer console](https://console.olaverselab.com):

```bash
export OLAVERSE_KEY="your-key"
```

Ask for what you want in plain words, or call the skill by name with `/olaverse-api`.

## Non-interactive installation

For scripts and CI, name the agent and accept the prompts:

## Install by hand

The skill is one Markdown file. Save [SKILL.md](/.well-known/agent-skills/olaverse-api/SKILL.md) as `.claude/skills/olaverse-api/SKILL.md` in your project (or `~/.claude/skills/olaverse-api/SKILL.md` for every project), or the equivalent folder for your agent.

<Aside type="tip" title="For any AI tool">
[`/llms.txt`](/llms.txt) lists every page of these docs with a one-line summary, for tools that read documentation directly.
</Aside>
