Every capability lives behind one base URL:

```text
https://api.olaverselab.com
```

<Steps>

1. **Create an API key.** Sign up at the [developer console](https://console.olaverselab.com) (new accounts start with $5 of free credit), open **API keys** and create one. It is shown once, so store it somewhere safe.

2. **Set your environment.**

   ```bash
   export OLAVERSE_URL="https://api.olaverselab.com"
   export OLAVERSE_KEY="your-key"
   ```

3. **Make a call.** This asks whether a customer wants a refund:

   <Tabs syncKey="lang">
   <TabItem label="curl">
   ```bash
   curl -X POST "$OLAVERSE_URL/v1/decide" \
     -H "Authorization: Bearer $OLAVERSE_KEY" \
     -H "Content-Type: application/json" \
     -d '{"state": "I was charged twice, please refund me",
          "questions": {"refund": {"type": "noul", "instructions": "The customer asks for money back."}}}'
   ```
   </TabItem>
   <TabItem label="Python">
   ```python
   import os, requests

   URL = os.environ["OLAVERSE_URL"]
   HEADERS = {"Authorization": f"Bearer {os.environ['OLAVERSE_KEY']}"}

   def call(path, body):
       r = requests.post(f"{URL}{path}", json=body, headers=HEADERS, timeout=120)
       r.raise_for_status()
       return r.json()

   result = call("/v1/decide", {
       "state": "I was charged twice, please refund me",
       "questions": {"refund": {"type": "noul", "instructions": "The customer asks for money back."}},
   })
   print(result["answers"]["refund"]["noul"])   # e.g. 0.97
   ```
   </TabItem>
   </Tabs>

</Steps>

The rest of these docs use the small `call` helper above in their Python examples.

## What's available

| What you want | Endpoint | From |
| --- | --- | --- |
| Typed decisions about a message or record | `POST /v1/decide` | $0.02 / 1M input tokens |
| A document as JSON, with a confidence per field | `POST /v1/extract` | $0.20 / 1M input tokens |
| The language of a text (608 languages) | `POST /v1/language-id` | $0.05 / 1,000 requests |
| Diacritics and tone marks restored (11 languages) | `POST /v1/diacritize` | $0.20 / 1M characters |
| Search-style questions from a passage (25 languages) | `POST /v1/questions/generate` | $0.04 / 1M input tokens |
| What's available | `GET /v1/models` | free |

Each POST endpoint also has a `/batch` version. Prices depend on the model; see [Pricing](/reference/billing/).
