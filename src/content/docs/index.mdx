Olaverse is an API for specialised language models built African-first. Use **Decisions** to route, flag and score messages with calibrated probabilities, **Document extraction** to turn receipts, mobile-money messages and forms into JSON, and **Language identification**, **Diacritic restoration** and **Question generation** for the text work around them. Every model is open-weight and sits behind one base URL and one API key.

## Supported models

| Capability | Models | Languages |
| --- | --- | --- |
| Decisions | `purplemist-flash-1.0` (7.9B) | English and eight African languages |
| Document extraction | `mist-extract-1.0` (4B), `mist-extract-flash-1.0` (2B) | English and African languages |
| Language identification | `lid-neural-608`, `lid-lite-608` | 608 |
| Diacritic restoration | `diacnet-2.0`, `diacnet-mini-2.0`, `diactag-2.0` | 11 |
| Question generation | `mist-qg-1.5b` | 25 |

Every model is published on [Hugging Face](https://huggingface.co/olaverse) with a model card. Call `GET /v1/models` for the live list, with each model's status, billing unit and price, or see the [model catalog](/reference/models/).
